# 界面语言与运维文案

本系统后台支持 **简体中文（zh_CN）**、**繁體中文（zh_TW）**、**English（en）**。

## 使用（运营）

- **切换**：登录页登录按钮下方的语言下拉框，或登录后顶栏右侧的地球图标下拉菜单。登录页的选择会在登录成功后写入该管理员账号，不会被账号里原来的语言盖掉。
- **默认**：还没选过语言时跟随浏览器。简体（`zh-CN` / `zh-Hans`）用简体中文，繁体（`zh-TW` / `zh-HK` / `zh-Hant`）用繁体中文，其它语言用英文。
- **记忆**：显式选择写入 session 和 cookie；登录后同步到 `admin_users.locale`（需已执行 `php artisan migrate`）。
- **系统外观**：**站点配置 → 系统外观** 按语言 Tab 填写名称与标题（仅存 `locales` 多语言块，不再支持旧版仅顶层 `system_name` 的 JSON）；Logo / Favicon 在选项卡下方上传，全平台共用。未上传时不使用默认 Logo 和 Favicon。
- **侧栏菜单**：优先按菜单 title / URI 映射语言包（`menu.uris.*` 等）。

## 展示范围

| 区域 | 语言 |
|------|------|
| 后台表单、列表、Toast、首页健康告警（`code` → `redi-health.*`） | 随当前界面语言 |
| 证书列表 **`last_error` 列正文** | **库内原文**（标签随界面语言；正文不翻译） |
| 新写入的 `last_error` / `last_error_code`、CLI、`redi:health` Webhook、节点 API 门控 | **英文 canonical**（`en/redi-errors`） |

证书错误在库内另有稳定字段 **`last_error_code`**（与 `redi-errors` 键一致），供程序判断；运维与后台仍主要看 `last_error` 英文说明。

## 开发防回退

改后台文案或运维消息时，在仓库根目录执行：

```bash
bash scripts/verify-admin-i18n-invariants.sh
bash scripts/verify-redi-lang-parity.sh
bash scripts/verify-redi-errors-invariants.sh
bash scripts/verify-redi-cert-error-code-invariants.sh
bash scripts/verify-ops-english-invariants.sh
```

发版前可跑完整 `bash scripts/dev-preflight.sh`。脚本说明见 [scripts/README.md](../scripts/README.md)。
